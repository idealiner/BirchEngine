# PrincessOwliviaCB v0.1.0

Initial public release.

## Highlights

- Core arcade gameplay with four stages
- Browser-playable build via WebAssembly
- Native Linux build and portable Linux bundle
- Splash art intro and themed UI
- High-score tracking with player name entry

## Web

- Main web entry file: PrincessOwliviaCB.html
- Deployable through GitHub Pages workflow

## Desktop Download

- Portable package: PrincessOwliviaCB-Linux-x86_64.tar.gz
- Contains AppDir with executable, assets, and bundled runtime libraries

## Known Notes

- Browser version is served over HTTP/HTTPS only (not file://)
- Native high-score XML is saved in the working directory
